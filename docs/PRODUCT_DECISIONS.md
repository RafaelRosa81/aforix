# Aforix - Product decisions

This document records product-level decisions that remain in force after the real-data acceptance campaign.

## Export tables

- Flat output is the default general-purpose export.
- `grouping=none` is the default.
- Daily and monthly pivot outputs remain available only when explicitly requested.
- An explicit `--flat` request overrides daily/monthly grouping and produces true flat output.
- The current workbook structure with separate export and metadata information is retained unless later usability testing justifies a redesign.

## Station identity

- `station_id` is the authoritative station identity.
- Station normalization may clean representation artifacts such as whitespace, case, or spreadsheet `.0` suffixes.
- Aforix must not invent aliases or renumber stations. For example, `P71` and `7071` are distinct identifiers.
- Legacy P-prefixed `station_code` values are not generated by default.

## SIH

- Configured semantic lookup values must resolve explicitly; unresolved configured values must not silently produce blank IDs.
- Lookup matching may normalize representation differences such as case and surrounding whitespace, but semantic substitutions belong in configuration/data rather than code.
- `id_operador` uses the first operator token from the source record. Split at punctuation or whitespace; for example, `Tiago Poren` becomes `Tiago`, `MV__RR` becomes `MV`, and `M. Reyes` becomes `M`.
- `lectura_escala` equals `escala_inicio`.
- Start and end dates are normalized into Summary before SIH export. FlowTracker uses the complementary table's last row for `fecha_fin`, Molinete combines `measurement_date` with `end_time`, and Nivus uses the archive-level `stime` for `fecha_inicio` and `etime` for `fecha_fin`.
- FlowTracker uses its only complementary-table reading for both scale fields when the table has one row. If the table is absent, table-dependent SIH fields are `S/D`.
- Molinete carries `escala_inicio` into `escala_fin` when the final-scale label is absent or its value is `-`.
- Nivus scale and operator fields remain unfilled for now, with normalized SIH mappings retained for future configuration.
- `nivel_confiabilidad` is deferred until a unified quality-evaluation model exists for FlowTracker, Molinete, and Nivus.

## Section profiles

- Station selection preserves authoritative station IDs.
- Supported chart types are `scatter` and `bar`.
- Molinete cross-section progression `progr_m` is the normalized source for `distance_m` when applicable.

## Current production scope

- FlowTracker, Molinete, and Nivus are the real-data-validated instrument paths covered by the current production integration.
- M9 remains outside the current production-complete scope.
- Commands or modules that remain placeholders must not be considered production-complete solely because a CLI entry exists.

## Acceptance evidence

- Detailed acceptance evidence remains preserved on `test/real-data-acceptance` and tag `milestone-real-data-acceptance-2026-10-06`.
- Acceptance-only configs, scripts, outputs, and campaign documents are intentionally not part of the production integration branch.
